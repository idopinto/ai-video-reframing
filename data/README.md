Add landscape videos here.

The pipeline and Streamlit app look for files in this folder:

    data/videos/your-clip.mp4

Supported extensions: `.mp4`, `.mov`, `.mkv`, `.m4v`, `.webm`, `.avi`.

Do not commit videos. This folder is gitignored except for `.gitkeep`.

Optional: a sibling file `data/titles.csv` with columns `file,title` gives the
evaluation app searchable descriptions.
